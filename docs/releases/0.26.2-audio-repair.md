# 0.26.2 — 试听补齐与错误文件修复

修复音频同步 full 模式仍只生成缺失对象的问题，允许定向替换已存在的错误鼓点、混音与纯音乐；上传使用强制覆盖，避免修改时间比较跳过修复。转换器使用当前发布版本的 Python，并将实际转换所需的 pydub、tqdm 纳入项目依赖和运行锁文件，防止独立发布环境只生成纯音乐而鼓点、混音因缺少依赖失败。

元数据匹配增加标题身份校验，禁止仅凭子串评分发布另一首歌的音频。TJA 声明的 WAVE 文件不存在时拒绝选取目录中的其他音频；未声明 WAVE 时仅接受唯一音频文件。包含扩展曲库的每日同步同时覆盖状态 1（包括尚未进入国服的国际服新曲），使已提供曲包的歌曲也能生成试听。转换队列按上架日期从新到旧处理，避免新曲等待历史扩展曲库补档。
