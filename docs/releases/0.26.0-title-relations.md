# 0.26.0 — 每日称号关联同步

09:42 Asia/Shanghai 的每日曲库任务在刷新官方称号目录后，使用当前歌曲目录生成带歌曲/官方称号 ID 的 Viewer 关系文件，再调用 Viewer 仓库中的同步工具，经已有管理接口补充本地称号资料。Viewer 后续页面请求直接读取更新后的关联，无需每天构建站点。单独维护可运行 `taiko_bot.offline.title_update --cached` 预览，加 `--apply` 发布。

同步使用 Git 外的 `/home/sigaer/taiko/data/title_sync.json`（权限 600），缺失配置或同步失败会令本轮任务报错。生成失败不进入接口发布；写入无自动重试；重跑从最新目录重新规划。已有人工条件和歌曲关联不清空，同名歧义和未完整匹配的歌曲跳过。

源码回归覆盖每日任务的失败传递、只预览不写入、显式目录/私有配置路径及既有歌曲处理、称号展示。Viewer 侧使用合成 HTTP 服务验证完整发布流程。历史 frozen 的四项曲库顺序对比在本轮修改及未修改的 HEAD 基线上均失败，原因涉及已存在的 OurTaiko/位置索引流程与旧冻结源差异；本轮不修改这些产品逻辑，只更新其称号发布边界 mock。未将这些历史对比计作通过。

自动发布启用前必须配置管理凭据并完成实际接口读回验收；源码和候选安装本身不代表线上称号资料已更新。
