# 0.25.7 — 修复联动名牌并自动清理旧运行环境

佩戴「悪魔の妹」时，广场资料的 `gameCostume.titleplate_id` 为底板编号 14，小程序映射同时提供称号 ID 947 与 `rarity: 14`。旧导入器按 947 保存图片，渲染器按 14 查找，导致名牌背景缺失。导入器现在优先使用明确提供的 `rarity`，未提供时沿用 `id`，兼容普通底板及 WEC 等共享图片。同步补齐 20 种联动名牌的普通/段位共 40 张资源，并更新名牌压缩包及总资源包。现有称号 ID 文件保留，不修改用户资料。

标准 `deploy_taiko.sh` 在新版本 Bot 健康检查通过后调用 `prune_releases.py`，删除更旧且未被引用的 `/opt/taiko-bot/releases/X.Y.Z`。当前版本、未来候选版本、目录符号链接、进程和 systemd/cron 配置引用的版本均保留。完成两次消费者扫描后才开始删除；扫描失败停止清理。清理不涉及业务数据、资源、其他项目或依赖 wheelhouse。HDU 上传等仍钉住旧版本的服务继续使用原环境，不为清理而重启它们。

验证覆盖导入编号、非法编号、普通底板兼容与资源包范围，以及中心端实际个人名牌渲染的普通/段位两种状态；清理验证当前/未来/引用保护、重新扫描时新增消费者、扫描失败、当前版本不匹配、外部符号链接和 dry-run。

发布通过标准候选构建、安装依赖检查与 Bot-only `scripts/deploy_taiko.sh 0.25.7 0`，资源构建使用已有隔离 build wrapper。新代码不新增 UI 文案或改变广场同步协议。
