# 0.26.4 / 0.26.5 新追加里谱与全难度元数据更新

旧更新链会用历史 raw 曲库中的缺失难度覆盖 Wiki，再仅为新歌曲填入 OurTaiko 难度，导致 HYPERNOVA 等已有歌曲追加里谱后长期无法显示。现在国行上架状态与全球谱面可用性独立处理；已有歌曲的新增单人难度也会进入元数据、评价、定数和图片链路。

新增独立的单人谱面同步模块，先更新 ESE，再按显式 AC 修订版本与谱面身份选择资源。无改谱的星级重新评定采用 Wiki 当前星级；分歧取 M（达人），不取最多音符的分支。双打歌曲以及 P1/P2 块不参与本次同步与图片生成。合法零音符谱面保留，难度字段中的 0 统一为无谱面。

全难度连击数和连打/气球信息不再依赖缺失定数来触发；确认连击数变化后失效对应定数，图片通过临时文件生成并替换，旧图片备份到 recovery_backups，失败保留重试队列。支持 OurTaiko 新 CDN 的固定路径和 SHA-256 校验，并按资源版本检查已缓存谱面更新。

修复工具 `python -m taiko_bot.offline.catalog_repair --stage PATH [--refresh] [--apply]` 在已有内存隔离 wrapper 内运行。先生成候选曲库，发布前校验全部原文件 SHA-256，再备份与发布公共文件；不写 userdata、历史、数据库或密钥。重复运行验证覆盖日更的 Wiki→OurTaiko→单人元数据链路。

仍无法取得可靠源谱的条目保留原有权威资料，并在 `logs/catalog_chart_sync_report.json` 记录具体冲突、缺少 COURSE 或源文件。不会为了消除告警而合成谱面音符或用其他版本填充。

0.26.5 补充分歧完整性修正：部分 TJA 的最后公共段仅编码为 N。按与图片引擎一致的逐段 M→E→N 回退计入达人路径；已有 M 的短段不从 N 补小节。该情况已添加回归测试。
