# 0.25.4 — Python 发布桥接协议修复

2026-11-19（Asia/Shanghai）。本次仅处理 Viewer 1.15.0 生产验收暴露的 stdout 协议污染，不重跑 Stage 0–5 UI 验收，不改变 JSON、API、数据库或成绩模型契约。

## 修复

`taiko_store.bridge.capture_current_measurement()` 原先先 import 每日计算模块，再重定向 stdout。冷进程首次 import 初始化 NoneBot 插件日志，向 JSON 行协议写入一行 `feature_handler` 加载成功日志。成绩文件已发布，但 Viewer 严格解析拒绝非 JSON，导致首次创建接口返回 503。

将该 import 移入原有 `redirect_stdout(sys.stderr)` 范围，覆盖导入和实际计算。协议响应仍只由 `send()` 输出，Viewer 继续严格解析每一行；不忽略杂行、不放宽协议。每日计算异常仍仅向 stderr 输出异常类型，不能把已提交成绩改判失败。其余发布、nonce、存储、锁及模型代码未改。

Bugfix 包版本为 0.25.4；runtime-lock 仅更新本包版本，其余依赖安装版本与 0.25.3 完全相同。Viewer 产品代码和版本不随 Python 修复改变。

- 标准 `scripts/build_release.sh` 构建并安装未激活候选 0.25.4（`qa-51f6c590128a`），`pip check` 通过。桥接源码与安装包文件 SHA-256 相同。
