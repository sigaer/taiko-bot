2026-11-12。由用户反馈“taikob20 实际收图 7～9 秒、此前约 20 秒”触发。本次完成真实生产分阶段计时，发布 Bot 0.21.3 / Application 0.8.3。运行代码提交 `26796e843c8748d610e7d532785f20b4143498f2`，标签 `v0.21.3`。本次运行代码只增加观测，没有更改评分、图片、权限和发送策略。

## 实测结论

观测到 6 条 QQ 官方群聊 `taikob20` v2 请求，均正常发送。按观测顺序首条为 9.843 秒，后续五条为 7.632、6.980、6.462、7.050、6.482 秒，后五条中位数 **6.980 秒**。这是线上自然请求的小样本描述，不是一次新的受控性能对比；未记录玩家身份，不将这些记录认定为同一个用户。

后五条中的主要阶段中位数：准备数据 1.216 秒、输入解冻/端口准备 0.275 秒、计算绘图 2.335 秒、图片上传 0.774 秒、消息发送 2.062 秒。这些来自不同请求，各阶段中位数不能相加。

最后一条请求按不重叠区间拆分如下，合计与发送成功回执计时一致：

|阶段|秒|
|---|---:|
|事件分发至计算开始：数据准备、解冻、授权、排队|1.507|
|计算、历史趋势及绘图、JPEG|2.053|
|计算后校验、消息构造和接口调用间隔|0.028|

该请求绘图排队仅 1.660 毫秒；7 次数据库连接加查询总计 70.587 毫秒。历史读取 0.515 秒包含在数据准备中；历史趋势重建与评分约 0.623 秒包含在计算绘图中；JPEG 编码 0.042 秒也包含在计算绘图中。以上子阶段不能再加入总耗时。

上传加发送约占这条请求总耗时的 44.6%，服务端其余准备与计算约占 55.4%。因此目前可以排除“主要耗时是绘图排队或数据库连接”的判断，也不能把全部差距归因于上传：消息发送接口的等待时间大于上传时间。API 时段含 SDK 编码、HTTP 连接、网络、服务端处理及响应解析，未进一步证明是腾讯审核、限流或纯网络往返。

## 为何此前离线数字约 0.4 秒

此前的合成场景冻结了成绩、历史和素材，真实 Matcher 基准使用模拟 SQL 和发送端。实际生产既有不同的输入与运行负载，又增加了真实上传和消息发送等待。此次实测计算绘图本身为 2.053～2.769 秒（后五条），不能用合成样本的 0.402 秒替代；没有读取或导出生产玩家成绩来推断具体成绩条数。

原合成样本的高密度用户没有历史，长期历史样本包含 350 条当前成绩，并未覆盖所有高密度与长期历史的组合。因此旧报告的受控加速比仍只适用于其固定输入，不能据此声称生产已达到亚秒响应。

首条观测的 command.parse 为 1.284 秒，后五条约 0.0003 秒；该阶段包含首次加载绘图模块。它说明进程首次请求存在额外初始化开销，不能与稳定连续请求混在一起。

## 计时边界与隐私

起点为 QQ adapter 将已解析的 Dispatch 事件转换为 Event 并建立异步处理任务前；终点为官方消息发送 API 成功返回。使用同一进程 perf_counter_ns 单调时钟，记录毫秒并保留三位小数。API 调用以请求内数据对象标识配对，标识仅在内存中短暂使用，不写日志。

该边界包含任务调度、NoneBot 路由、授权、准备、排队、计算、上传和发送返回；不包含用户手机发出消息到 QQ 事件到达前的网络时间，也不能确认客户端实际显示图片的时刻。接口成功返回代表平台受理，不等于用户已看见。日志不含 QQ/群/鼓众 ID、绑定、成绩、消息正文、图片、API 参数或返回内容；只有随机请求编号、命令类别和耗时。

所有 span 都是 inclusive 区间，可有父子嵌套。原始记录保留开始偏移与耗时，不能将所有 span 累计后当成总耗时。

## 已确认的后续优化位置

数据准备中包含历史 JSON 读取、完整历史观察摘要和 PreparedPrivateInput.freeze；进入绘图前 build_ports 又将历史 thaw 为请求独占数据。线上可见输入解冻约 0.24～0.48 秒，准备内部仍有约半秒未被独立命名的观察摘要/冻结等操作。可继续细分和减少等价的数据复制；不能为速度删除观察绑定或发送前权限复核。

历史趋势计算在这些请求中约 0.598～1.018 秒（后五条），需要继续评估完全相同修订下的重复计算。任何结果复用都必须绑定玩家、授权状态、历史修订、算法和曲库修订。

官方发送 API 的 1.825～2.420 秒与上传的 0.705～0.954 秒（后五条）需要独立评估 HTTP 连接与接口侧耗时。当前并未证明改用某种传输方式能够消除这部分时间，不以降低 JPEG 质量、公开私人图片或全局缓存最终图片换取速度。
