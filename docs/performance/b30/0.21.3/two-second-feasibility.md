# 完整 B20 图片响应低于 2 秒的可行性核对

2026-11-12，生产版本 Bot 0.21.3 / Application 0.8.3。本轮回答完整图片响应能否稳定低于 2 秒；没有改变生产发送策略、代理、评分、素材、图片质量或资源限制。

结论：可继续减少服务器处理，但目前没有已验证的方案能保证 QQ 官方机器人完整图片稳定低于 2 秒。既有同一请求实测总耗时 6.482 秒，上传加消息发送即为 2.894 秒。这个数字是当前调用链的观测值，并非物理下限；它还包含 SDK、调度、HTTP、网络和平台处理，不能断言不可优化。

## 验证一：连接复用

已核实安装的 QQ adapter 默认 API 为 `api.bot.qq.com`，生产环境及实际配置没有 API 域名覆盖和 HTTP 代理配置。探测仅在隔离 QA 内使用与生产对应的直连策略，不修改生产代理。没有使用 Bot 账号、令牌或发送消息。

在真实 API 域名根路径做未鉴权 GET，各模式 7 次，排除第一条后各保留 6 次。全部返回 HTTP 404。统计包含每次独立客户端的创建、请求和关闭；复用模式只创建一次客户端。

|模式|热请求中位数|最大值|
|---|---:|---:|
|每次新建连接|51.422 ms|63.484 ms|
|复用连接|30.453 ms|58.759 ms|

本轮差值 20.969 ms。另一轮仅计请求 await 的比对差值约 30 ms。它们说明连接复用值得小幅优化，但这些 GET 结果不能证明能消除真实发送接口约 2 秒的等待，也不能充当鉴权 POST 的优化前后对比。没有据此引入新的客户端池或宣称生产加速。

初步探测曾使用官方文档里的旧域名 api.sgroup.qq.com；确认安装版默认域名后，以实际域名重测。上表及附带 JSON 均使用后者。运行单元 qa-6ea4dc38ad7d；原始数据见 two-second-http-probe.json。

## 验证二：事件循环可用性

90 秒内每约 250 ms 读取一次本机 `/internal/bot-pool`，保留状态码和耗时，不保留响应内容或 Bot ID，共 348 次，零错误。中位数 2.614 ms，P95 9.538 ms，最大 315.829 ms。

该窗口没有出现新的 B30 请求，所以这些空闲期观测不能排除 B30 计算期间的事件循环阻塞，更不能把所有 API await 时间算为腾讯侧处理。需要与真实请求重叠的调度或网络子阶段观测才能进一步归因。运行单元 qa-ccd779cb711e，原始数据见 two-second-loop-probe.json。

## 不直接采用上传即发送

腾讯官方富媒体文档规定 `srv_send_msg=true` 会直接发送并占用主动消息频次；当前实现使用 `false` 获取 file_info 后回复。自动发送不是现有被动回复的等价替代，且不携带现有消息接口的相同正文与引用。官方发送消息文档还说明主动推送能力已调整，不能把合并成一个接口当作安全、等价的优化。

来源：[腾讯官方富媒体文档](https://github.com/tencent-connect/bot-docs/blob/main/docs/develop/api-v2/server-inter/message/send-receive/rich-media.md)、[腾讯官方发送消息文档](https://github.com/tencent-connect/bot-docs/blob/main/docs/develop/api-v2/server-inter/message/send-receive/send.md)。

## 值得继续实施验证的路径

1. 在相同玩家、授权状态、当前成绩、历史、算法与曲库修订下复用小型派生摘要，减少历史重建与评分重复计算。不能缓存完整玩家成绩或最终私人图片，也不能删掉发送前授权复核。
2. 减少历史数据在准备、冻结、解冻和渲染之间的等价重复复制。当前生产已有约 0.24～0.48 秒输入准备，以及历史准备和评分耗时的证据；节省量必须通过同条件复测确认。
3. 若完全相同图片已经上传，可评估仅复用有效期内的 QQ 媒体凭据；凭据需要按 Bot、接收场景、目标、授权状态及内容哈希严格隔离，每次发送仍需重新授权。官方文档允许复用 file_info，但这不等于已完成安全缓存实现，也不等于不需要绘图或发送调用。

这些路径尚未实现和测出独立收益，不把假定节省时间作为结果。稳定完整图片低于 2 秒仍要同时满足服务器准备/绘图及官方调用的总预算。若允许先发文字或链接再显示图片，那是另一种交互目标，不能当成完整图片两秒验收通过。

本轮没有可证明收益达到目标的生产补丁，因此生产继续运行已验收的 0.21.3，避免把低收益或改变业务语义的尝试直接上线。
