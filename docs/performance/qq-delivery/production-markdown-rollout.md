# QQ 官方图片默认 Markdown（0.23.0）

日期：2026-11-13（Asia/Shanghai）。用户在五轮对照实验后明确选择将 `taikobxx` 和其他图片回复切换为方案 C。本次是按该选择修改生产发送策略；此前实验报告的“不自动切换”结论保留为当时的审计快照。

## 发送行为

官方 QQ 的中心、客户端、公共歌曲/谱面和社区图片入口统一调用 `taiko_bot.runtime.qq_images.build_qq_image_reply`。正文、图片尺寸标记和原有按钮合为一条 Markdown，不再为正常图片先上传 QQ 媒体；Markdown 图片不附带引用。成绩汇总和客户端你画我猜原有图片直发也接回该策略。

OneBot 仍发送原图片消息，客户端你画我猜仍保留图片在说明文字前的顺序。年度报告原本已经使用 Markdown，保留其专用跳转按钮并使用中心统一缓存。

仅本地缓存失败时沿用富媒体回退；Markdown 请求超时或未知结果不补发图片。原有明确被动回复额度/窗口错误 `40034128` 的主动发送处理保留，发送的仍是同一条 Markdown。

## 缓存与授权

中心发送入口和启动清理任务共用 `center_markdown_media`；客户端入口与客户端启动清理任务共用 `taiko_runtime.qq_markdown_media`。不再由玩家发送模块各自写入另一份缓存。

缓存原子发布完整文件，在进程 umask 077 下仍将专用缓存目录设为0755、图片设为0644，供静态服务读取。随机文件名不含玩家标识。权限门面在写入公网缓存前和实际发送前分别复核，撤销后不能创建新的图片缓存或发送。

此策略会使真实玩家图片可通过随机 HTTPS URL 访问。URL持有者可在有效期内读取；源文件默认30分钟后由每5分钟运行的清理任务删除，CDN/客户端缓存可能延长可见时间。这不是登录鉴权下载，也不保证永久回看历史 QQ 图片。
