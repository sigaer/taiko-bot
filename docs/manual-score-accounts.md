# 手动成绩账号使用说明

手动成绩账号是一种不绑定鼓众广场（Wahlap）或ドンだーひろば（Hiroba）的独立账号。你可以自行录入成绩，并继续使用 B30、进度、我的小咚、年度总结和分享等功能。

手动账号可以与已有的国服、日服账号同时存在，并通过 `u1`、`u2` 等槽位切换。

## 适合哪些情况

- 没有鼓众广场或 Hiroba 账号，但希望记录自己的成绩。
- 想记录线下、旧版本或尚未收录的曲目成绩。
- 想把同一份手动成绩同时用于 viewer 和 bot。
- 想把手动记录与官方账号分开保存。

## 重要说明

- 手动成绩会明确标记为“手动录入”。
- 手动成绩可以用于自己的查询、B30、进度和分享。
- 手动成绩不会进入官方排行榜、官方认证统计或官方账号合并结果。
- `u0` 只合并国服和日服官方账号，不包含手动账号。
- `taikoupdate` 和“更新hiroba”不能更新手动账号。
- 手动账号的成绩保存在中心，viewer 与 bot 看到的是同一份数据。

## 在 bot 中创建账号

发送：

```text
新增空白账号 我的练习号
```

昵称可以省略：

```text
新增空白账号
```

创建完成后，新账号会成为当前槽位。绑定摘要会显示为：

```text
u1:国服账号(CN) / u2:我的练习号(手动)（当前）
```

系统内部账号 ID 不会展示给用户。

## 在 viewer 中创建账号

1. 登录 [太鼓成绩 Viewer](https://viewer.sakura-bot.cn)。
2. 打开“个人档案”。
3. 选择“新建手动账号”。
4. 输入昵称并确认。
5. 前往成绩页面添加成绩。

手动账号卡片会显示“手动”来源印章，不会显示外部同步和谱面锁选项。

## 多账号切换

发送对应槽位即可切换：

```text
u1
u2
u3
```

其中：

- `u1`、`u2` 等代表真实账号槽位。
- 手动账号与国服、日服账号共用槽位编号。
- 删除或解绑账号后，槽位会自动压紧，不会留下空号。
- `u0` 是国服、日服官方账号的只读合并槽位，不包含手动成绩。

## 录入或更新成绩

基本格式：

```text
录入成绩 <歌曲ID或曲名> <难度> <分数> <良> <可> <不可>
```

示例：

```text
录入成绩 123 魔王 987650 500 8 2
```

同一首歌、同一难度已有成绩时会更新，没有时会新增。

### 可选统计

可以继续追加：

```text
连打=n
连击=n
评价=n
游玩=n
通关=n
全连=n
全良=n
```

完整示例：

```text
录入成绩 123 魔王 987650 500 8 2 连打=36 连击=490 评价=4 游玩=3 通关=3 全连=1 全良=0
```

所有数值必须是非负整数，最大连击不能超过良、可、不可的总物量。

### 难度写法

| 数字 | 中文 |
| --- | --- |
| `1` | 简单、梅 |
| `2` | 一般、竹 |
| `3` | 困难、松 |
| `4` | 魔王、鬼、表 |
| `5` | 里谱、里 |

### 曲名包含空格

曲名包含空格时，请使用引号：

```text
录入成绩 "My Song Name" 魔王 950000 480 15 5
```

### 未收录曲目

未收录曲目需要使用数字 ID，并提供曲名：

```text
录入成绩 999999 里谱 980000 600 10 2 曲名="自定义曲名"
```

这个数字 ID 应保持固定，之后查询和更新都使用同一个 ID。

### 曲名有歧义

如果搜索到多首歌曲，bot 会列出候选歌曲及 ID。请改用准确的歌曲 ID 重新发送命令。

## 查看成绩

```text
查看成绩 <歌曲ID或曲名> <难度>
```

示例：

```text
查看成绩 123 魔王
查看成绩 "My Song Name" 里谱
查看成绩 999999 5
```

返回结果会包含分数、良、可、不可、连击，并标记“手动录入”。

## 删除成绩

先发送：

```text
删除成绩 <歌曲ID或曲名> <难度>
```

然后在提示时间内发送：

```text
确认删除成绩
```

删除后，相关成就统计和历史会重新计算。

## 修改账号昵称

先切换到目标手动账号，然后发送：

```text
空白账号改名 新昵称
```

改名会同步到 viewer、bot、个人资料和后续历史记录。

## 在 viewer 与 bot 之间认领账号

认领可以让同一个手动账号同时属于：

- 1 个 viewer 用户；
- 1 个 bot 消息平台身份。

账号不能同时绑定给两个 viewer 用户或两个 bot 身份。需要换号时，请先在原身份解绑。

### 从 bot 认领到 viewer

1. 在 bot 中切换到目标手动账号。
2. 发送：

   ```text
   生成认领码
   ```

   也可以指定槽位：

   ```text
   生成认领码 u2
   ```

3. 登录 viewer。
4. 在“个人档案”选择“认领手动账号”。
5. 输入认领码。

### 从 viewer 认领到 bot

1. 在 viewer 的手动账号操作中生成认领码。
2. 在需要绑定的 bot 身份中发送：

   ```text
   认领空白账号 ABCD2345
   ```

### 认领码规则

- 认领码为 8 位，不使用容易混淆的字符。
- 认领码 10 分钟内有效。
- 每个认领码只能使用一次。
- 新生成认领码后，之前未使用的认领码会失效。
- 不要把认领码发送到公开群聊或交给其他人。

如果 bot 在认领后提示认领码已使用，请先查看绑定摘要或尝试切换账号。认领写入可能已经成功，不要连续生成或提交多个认领请求。

## 公开与隐藏

切换到目标手动账号后发送：

```text
给看
```

允许其他人查询。

发送：

```text
不给看
```

禁止其他人查询。

即使允许公开查询，结果仍会标记“手动录入”，且不会进入官方排行或认证统计。

## 解绑账号

普通解绑只会移除当前端的绑定，另一端和成绩仍然保留。

```text
解绑空白账号
```

也可以指定槽位：

```text
解绑空白账号 u2
```

如果当前端是账号的最后一个持有者，普通解绑会被拒绝。此时需要决定是保留账号，还是永久删除。

## 永久删除账号

先发送：

```text
永久删除空白账号
```

或指定槽位：

```text
永久删除空白账号 u2
```

然后发送：

```text
确认永久删除空白账号
```

永久删除会清理：

- viewer 与 bot 的绑定；
- 全部手动成绩；
- 成绩历史和账号资料；
- 未使用的认领码；
- 相关账号配置。

永久删除面向用户视为不可撤销，请在操作前确认账号和槽位。

## 常见问题

### 为什么不能使用 `taikoupdate`？

手动账号没有关联鼓众广场或 Hiroba，不存在可拉取的官方数据。请使用“录入成绩”维护成绩。

### 为什么 `u0` 看不到手动成绩？

`u0` 专门用于合并国服和日服官方账号。手动成绩被刻意排除，避免与官方成绩混合。

### 为什么最后一个持有端不能普通解绑？

如果最后一个持有端也解绑，账号会变成无人可访问的数据。系统会要求使用带二次确认的永久删除，避免误操作。

### 认领码提示已使用怎么办？

先查看当前绑定摘要，或发送对应的 `uN` 切换命令。认领可能已经完成，只是回复过程中出现了网络或摘要查询异常。

### viewer 和 bot 的成绩不一致怎么办？

手动成绩由中心统一保存，正常情况下两端会立即互相可见。可以刷新 viewer 页面或重新查询；仍不一致时，请记录操作时间、账号昵称、歌曲 ID 和难度后反馈。

### 能把手动账号转换成国服或日服账号吗？

不能。手动账号与 Wahlap/Hiroba 官方账号是不同的数据来源。需要官方账号时，请另外绑定一个 CN 或 JP 槽位。
